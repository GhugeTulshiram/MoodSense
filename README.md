# 🎵 MoodSense

## Smart Facial Emotion Detection and Personalized Music Experience Platform

MoodSense is a smart music platform that detects a user's facial emotion
through a camera and recommends personalized music according to the
detected mood.

---

## ✨ Key Features

- 📷 Real-time Face Detection
- 😊 Facial Emotion Detection
- 🎵 Emotion-Based Song Recommendation
- 🎧 Personalized Music Experience
- 🔗 Spotify API Integration
- ▶️ Interactive Music Player
- 💻 Modern and Responsive User Interface
